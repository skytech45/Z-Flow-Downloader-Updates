# Z-Flow Downloader Updates

Public update metadata and release assets for Z-Flow Downloader.

- Update feed: <https://raw.githubusercontent.com/skytech45/Z-Flow-Downloader-Updates/main/versions.json>
- Releases: <https://github.com/skytech45/Z-Flow-Downloader-Updates/releases>
- Standalone Chromium extension archives: [`dist/extensions/`](./dist/extensions/); the current version, download path, and SHA-256 are recorded in `versions.json` under `extension`.

Each public release includes platform binaries and the corresponding GPL-3.0 source archive. Feature-pack update archives are served from `dist/packs/`.
